## About the data

The reporting uses listings advertised through [NC State’s Off-Campus Housing website](https://offcampus.dasa.ncsu.edu/housing), collected on September 9, 2026. The article analyzes reviewed room/per-bedroom prices near Main Campus, Centennial Campus and Centennial Biomedical Campus. Campus map layers come from NC State Facilities GIS.

These advertised offers are a snapshot, not a complete inventory of Raleigh rentals or a measure of students’ actual housing costs. Sources, exclusions and calculations are documented in the references and Excel audit. Street-address text for listings marked as hidden by the portal has been removed from the public data.
